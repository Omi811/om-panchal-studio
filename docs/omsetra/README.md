## Problem Solved
Indian housing societies, CAs, and SMEs are trapped paying annual Tally and cloud SaaS renewals for bloated software that leaks financial data to third-party servers.

## Architecture Summary
Enforces strict mathematical double-entry invariants locally in the browser with cryptographic balance verification, instant trial balance generation, and offline persistence.

## Key Capabilities
- Zero-drift debit/credit invariant enforcement on every journal voucher
- Tailored chart of accounts for Indian Co-operative Housing Societies & SMEs
- 100% local data sovereignty with encrypted JSON snapshot backup/restore
- Turnkey white-label licensing for accounting firms and society portals
