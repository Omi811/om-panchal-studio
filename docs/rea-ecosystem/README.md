## Problem Solved
Large TypeScript and React codebases suffer from circular dependencies, dead bundle bloat, and context loss when onboarding engineers or prompting coding agents.

## Architecture Summary
Parses repository AST structures into an interactive, deterministic dependency graph that pinpoints bundle bottlenecks and exports compressed architectural context.

## Key Capabilities
- Instant AST-level component dependency and prop-flow visualization
- Dead-code and heavy module dependency detection for speed sprints
- Compact architectural memory export for LLM context windows
- Available as both a CLI utility and an interactive studio audit session
